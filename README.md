# BoatSimulator

ボートレースの買い方・戦略を、過去のレース結果データに適用して検証する **Java製CUIシミュレーター** です。

ユーザーが登録した戦略を複数レースへ適用し、的中数・的中率・投資額・払戻額・損益・回収率を確認できます。

---

## 概要

「この買い方を続けた場合、どのような結果になるのか」を、感覚ではなく過去データを使って確認することを目的に制作しました。

実際に舟券を購入するアプリではなく、登録した戦略を過去レースへ適用する **シミュレーション用アプリ** です。

## 主な機能

### 戦略管理

- 戦略の新規登録
- 戦略一覧表示
- 戦略詳細表示
- 戦略検索
- 戦略編集
- 戦略削除

### 対応券種

- 単勝
- 複勝
- 2連単
- 3連単
- 2連複
- 3連複

### 買い方

- 通常買い
- フォーメーション
- BOX

### レースデータ

CSVファイルからレース結果を読み込み、シミュレーションに使用します。

現在のテストデータでは、2026/9/12 複数会場・全156レース分の実データを読み込める構成にしています。

### シミュレーション結果

以下を集計して表示します。

- 対象レース数
- 的中数
- 的中率
- 総投資額
- 総払戻額
- 総損益
- 回収率

## シミュレーション例

3連単フォーメーションで、次の戦略を登録した場合：

```text
1着候補：[1]
2着候補：[2, 3]
3着候補：[2, 3, 4]
1点賭け金：100円
```

生成される有効な買い目：

```text
1-2-3
1-2-4
1-3-2
1-3-4
```

同じ艇が複数着になる、

```text
1-2-2
1-3-3
```

などの組み合わせは除外します。

この場合、1レースあたりの投資額は、

```text
4点 × 100円 = 400円
```

として計算されます。

## 各クラスの役割

### `Main`

CUIのメニュー表示、ユーザー入力、各Serviceの呼び出しを担当します。

### `Strategy`

1つの戦略を表すモデルです。

主に以下の情報を保持します。

- 戦略ID
- 戦略名
- 券種
- 買い方
- 1着候補
- 2着候補
- 3着候補
- 1点あたりの賭け金

### `RaceResult`

1レース分の結果データを保持します。

- 日付
- 会場
- レース番号
- 1〜3着
- 各券種の払戻情報

などを管理します。

### `StrategyService`

戦略の登録・検索・編集・削除など、戦略管理に関する処理を担当します。

### `SimulationService`

戦略とレース結果を組み合わせ、

- 買い目生成
- 的中判定
- 投資額計算
- 払戻計算
- 集計

を行います。

### `CsvLoader`

CSVファイルを読み込み、`RaceResult`へ変換します。

## データ構造

戦略の買い目は `ArrayList<Integer>` を利用して管理しています。

例：

```java
firstChoices  = [1]
secondChoices = [2, 3]
thirdChoices  = [2, 3, 4]
```

複数の艇番をListとして保持することで、通常買いだけでなくフォーメーションにも対応できるようにしています。

## 工夫した点

- 全体的に `ArrayList` を活用し、関連するデータをまとまりとして扱うことを意識しました。
- パッケージ構成、メソッド名、Gitのコミット文などで使用する英単語も調べながら、役割が分かりやすい命名を意識しました。
- `enum` と `switch` を利用して、券種や買い方を扱いやすくしました。
- CSVから複数レースのデータを読み込み、まとめてシミュレーションできるようにしました。
- フォーメーションでは、多重ループを利用して有効な買い目を生成しています。
- 2連複・3連複では順不同になるため、同一買い目を重複して数えないようにしています。

## 苦労した点

### フォーメーションのシミュレーション

単純に候補を組み合わせるだけでは、同じ艇が複数着に入る成立しない買い目まで生成されるため、除外処理が必要でした。

### CSVインポート

CSVの読み込み方法、文字列から数値への変換、空欄データの扱いなどを学びながら実装しました。

### コードの肥大化

機能を追加するにつれて `Main` や `StrategyService` のコード量が増え、処理をどのクラス・メソッドへ分けるかが課題になりました。
